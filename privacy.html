Privacy Policy

Effective date: March 9, 2026

This Privacy Policy describes how ASAP Mobile ("we", "our", or "the application") collects, uses, and protects user information.

This application is operated by ASAP Poliglota / Wellington Pires.

1. Information We Collect

When users create an account in the application, we collect the following information:

  • Email address (used as the account username)
  • Contact email address
  • First name
  • Last name

2. User Generated Content

The application allows users to create conversations through text messages. Messages and conversation history may be stored in our database in order to provide the core functionality of the service.

3. Voice Input and Transcription

The application may allow users to send voice input. Voice input may be transcribed into text to enable communication features. The resulting text may be stored in our database as part of the conversation history.

Audio recordings themselves are not stored unless explicitly stated by the application.

4. How We Use the Information

The collected information is used for the following purposes:

  • Creating and managing user accounts
  • Authenticating users
  • Providing messaging and conversation features
  • Storing and managing conversation history
  • Maintaining and improving the application's functionality
  • Providing user support when necessary

5. Analytics

In the future, the application may use analytics tools to better understand how users interact with the application and improve the user experience. These tools may collect anonymous usage information.

6. Data Storage

User data and conversation data are stored on secure servers hosted on a Virtual Private Server (VPS) infrastructure located in Brazil.

7. Data Security

We implement reasonable technical and organizational measures to protect user information against unauthorized access, loss, misuse, or alteration.

Data transmitted between the application and our servers is protected using HTTPS encryption.

8. Data Retention

User information and conversation data are stored for as long as the user account remains active or as necessary to provide the service.

Backup copies of data may be retained temporarily for security and system recovery purposes.

9. Account Deletion

Users can delete their account directly from within the application through the account settings.

When an account is deleted, associated personal information and conversation data are permanently removed from our systems, except where retention is required for legal or security purposes.

10. Data Sharing

We do not sell, rent, or trade personal user data.

Information may only be shared when required by law or when necessary to operate the infrastructure required to provide the service.

11. Changes to This Policy

We may update this Privacy Policy from time to time. When updates occur, the new version will be published on this page with an updated effective date.
